This is a recreation of Fandom's wiki chatrooms, where I met some friends that I still talk to today. They were removed in the United Community Platform update that rolled out in 2019-20. Years later, with some software engineering knowledge, I decided to build an web app to recreate the old chatroom's old functionality and design with modern tools. 

* Frontend: Vite with React
* Backend: Express.js with TypeScript
* Database: PostgreSQL

For the messaging, I also use Socket.io for websocket based client-server connections.

**WIP. First release expected later this year.**
